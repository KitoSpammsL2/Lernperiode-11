## Grob-Planung

Erklären Sie Ihre Projekt-Idee in einem Satz, als müssen Sie einen Investor davon überzeugen.

Erklären Sie, welche technischen Herausforderungen Sie in Ihrem Projekt erwarten.

Beschreiben Sie, welche nicht-technischen Aspekte Sie in diesem Projekt besonders üben möchten.

Ich möchte eine Blackjack-App in Kotlin entwickeln, in der man gegen einen Dealer spielen kann. Eine technische Herausforderung wird für mich die Spiellogik mit den Karten und das Speichern des Spielstands sein. Ausserdem möchte ich besonders üben, mein Projekt gut zu planen und Schritt für Schritt umzusetzen.
